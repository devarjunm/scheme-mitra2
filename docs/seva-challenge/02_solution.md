# 02 — Solution

**Scheme Mitra** is a farmer-first eligibility-to-action layer. It asks for a small farm profile, evaluates published conditions with a deterministic engine, explains the matching and missing information, presents a staged document checklist, and routes the farmer to the official portal.

The initial innovation is operational, not “AI finds schemes”:

```text
Farmer profile → source-backed rules → explainable fit → document readiness → official next step
```

The first build is a demo, not yet a validated service. Distinction from existing discovery portals must be tested with users and articulated using verified product comparisons. Avoid claiming that no similar tool exists.
