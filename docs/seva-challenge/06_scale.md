# 06 — Scale

Proposed sequence, conditional on evidence and department approval:

1. Test the workflow with 10 consenting farmers and an agriculture-domain reviewer.
2. Refine and evaluate with up to 50 farmers in one proposed community/site.
3. Expand to 100–500 only if the first phase is useful, accurate and supportable.
4. Pilot one taluka; then one district; then consider additional Maharashtra districts.
5. Expand scheme categories/states only with local data owners and source-verification capacity.

At every stage measure local relevance, time, comprehension, support cost, data freshness and unintended harm. The architecture allows more districts, but technical extensibility is not evidence that operational scale is ready.
