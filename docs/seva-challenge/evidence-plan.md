# Seva First evidence plan

## Field interview form (draft)

Collect only with informed consent. Do not record Aadhaar, account numbers, private land records or names unless there is a justified, consented research protocol.

- Participant code (random, non-identifying): `[CODE]`
- Date / village / taluka: `[DATE] / [LOCATION]`
- Participant count to date: `[ACTUAL COUNT]`
- Farmer profile relevant to the task (optional, minimized): `[FIELD NOTES]`
- Last time they looked for a government agriculture scheme: `[WHEN / PURPOSE]`
- How did they search or get help? `[CURRENT PROCESS]`
- How long did it take? `[OBSERVED / REPORTED TIME]`
- What was confusing? `[VERBATIM OR SUMMARY, CONSENTED]`
- Could they name a relevant scheme? `[YES / NO / UNSURE]`
- Could they identify required documents? `[YES / NO / UNSURE]`
- What happened next? `[OUTCOME / NO OUTCOME]`
- How often does this issue arise? `[FREQUENCY / RECALL WINDOW]`
- Evidence capture method and consent: `[METHOD]`

## Baseline / post-use measures

Use the same farmer task where possible. Record:

- elapsed time to identify a potentially relevant scheme;
- number of sources/visits/searches used;
- participant explanation of why it may fit;
- documents correctly identified vs unknown;
- participant can state the next official step;
- confidence/self-rating with the exact question and scale;
- accessibility/language assistance required;
- errors, dead ends, incorrect or stale information observed.

## Post-use feedback

- Was the shortlist useful? Yes / No / Unsure.
- What felt irrelevant or unclear?
- Could you explain the profile-match score correctly?
- What documents are missing, if any?
- What action would you take next?
- Did you reach the official portal? If yes, what happened? (Do not capture credentials.)
- Would you want a local agriculture worker to review it with you?
