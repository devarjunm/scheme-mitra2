# 03 — Method and feasibility

## Current stage

Runnable web MVP with a synthetic Nashik farmer profile, three official-page summaries, deterministic profile-fit ranking, source links, self-reported document checklist, manual application tracker and local feedback/evidence capture.

## Next validation method

1. Review source records and wording with a qualified Maharashtra agriculture-domain verifier.
2. Interview farmers and local service staff before changing the problem statement.
3. Conduct moderated usability sessions; observe time, comprehension and the ability to identify the next official action.
4. Run a bounded pilot with consent and a baseline/post-use instrument.
5. Report limitations, cohort, sample size and unresolved conditions alongside results.
